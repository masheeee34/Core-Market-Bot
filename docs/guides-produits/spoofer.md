# ⚡ Guide SPOOFER PERMANENT (HWID)

### 🛡️ À quoi sert le Spoofer ?
Le Spoofer HWID modifie temporairement ou de façon permanente les identifiants matériels de votre ordinateur (Numéro de série Carte mère, Disques SSD/NVMe, Carte Réseau MAC, UUID, GPU).
Il permet de rejouer en toute sécurité après un shadowban ou un ban matériel.

---

### 📋 Procédure d'Utilisation
1. Fermez tous les launchers de jeux (Battle.net, Steam, Riot Vanguard).
2. Lancez le **SPOOFER** en tant qu'administrateur.
3. Choisissez l'option **Spoof All**.
4. Attendez le message de confirmation (Success).
5. Lancez votre jeu avec un compte propre.
