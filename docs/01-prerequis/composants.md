# 2. Composants & Runtimes Requis

Pour éviter les erreurs du type `VCRUNTIME140.dll manquant` ou `D3DCompiler introuvable`, vous devez installer les bibliothèques C++ et DirectX.

---

### 1. Visual C++ Redistributable All-In-One (AIO)
Ce package installe toutes les versions officielles de Microsoft Visual C++ de 2005 à 2026 en une seule fois.

* Téléchargez le package **Visual C++ AIO**.
* Extrayez l'archive ZIP.
* Faites un clic droit sur `install_all.bat` > **Exécuter en tant qu'administrateur**.
* Laissez l'installation se terminer (les fenêtres noires se ferment d'elles-mêmes).

---

### 2. DirectX End-User Runtimes
* Téléchargez le programme d'installation Web DirectX de Microsoft.
* Lancez l'exécutable, décochez la barre Bing si proposé, et terminez l'installation.

---

### 3. Redémarrage
Une fois ces deux composants installés, **redémarrez votre ordinateur**.
