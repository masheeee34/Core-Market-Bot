# 🎯 Colorbot (Full & Lite) — Guide d'Utilisation

Le **Colorbot Valorant** analyse les pixels d'affichage en temps réel pour verrouiller la tête ou le torse des adversaires avec une précision chirurgicale sans injection de mémoire interne.

---

### ⚙️ 1. Configuration en Jeu (Valorant)
1. Lancez **Valorant**.
2. Allez dans **Paramètres** > **Général** > **Accessibilité**.
3. Définissez la **Couleur de contour des ennemis** sur :
   * **Violet (Deutéranopie)** *(Recommandé)*
   * **OU Jaune (Protanopie / Deutéranopie)**
4. Mettez le mode d'affichage en **Plein écran sans bordure (Fullscreen Borderless)** ou **Plein écran**.

---

### 🎛️ 2. Réglages Recommandés

#### Configuration « Legit » (Indétectable aux spectateurs)
* **FOV (Rayon de visée) :** `25 - 40`
* **Smooth (Lissage) :** `15 - 25`
* **Target Bone :** Tête (`Head`) / Cou (`Neck`)

#### Configuration « Semi-Rage »
* **FOV :** `60 - 90`
* **Smooth :** `4 - 8`
* **Target Bone :** Tête (`Head`)

---

### 🌐 Dashboard Web (Colorbot Full)
Pour la version **Colorbot Full**, vous pouvez ajuster tous les paramètres en direct depuis votre navigateur sur votre smartphone ou second écran sans quitter le jeu.
