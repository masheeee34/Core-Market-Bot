# ⚡ Triggerbot Standalone — Guide d'Utilisation

Le **Triggerbot** tire automatiquement à la milliseconde près dès qu'un ennemi traverse votre réticule de visée.

---

### ⚙️ 1. Paramètres Clés

| Paramètre | Description | Valeur Recommandée |
| :--- | :--- | :--- |
| **Delay Before Fire** | Délai en millisecondes avant le premier tir | `40ms - 80ms` (Legit) / `0ms` (Instant) |
| **Delay Between Shots** | Cadence de tir entre deux balles (Vandal/Phantom) | `120ms - 180ms` |
| **Keybind (Touche)** | Touche d'activation du Triggerbot | Bouton Souris 4/5 ou `Shift` |
| **Trigger Mode** | Maintien (`Hold`) ou Bascule (`Toggle`) | `Hold` (Maintien) |

---

### 💡 Conseils pour Opérateur & Sniper (Operator / Marshal)
* Avec les snipers, réglez le **Delay Before Fire** sur `0ms` ou `15ms`.
* Vous pouvez tenir une ligne serrée : le tir partira automatiquement à l'instant où l'adversaire peek.
