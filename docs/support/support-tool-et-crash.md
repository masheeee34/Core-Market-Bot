# 🔧 Outils de Support Automatique

### 🧰 Support Tool & Pré-requis
Si le loader ne se lance pas ou affiche un message d'erreur de driver manquant :

1. Téléchargez et installez les **Visual C++ Redistributable All-in-One** (2015 à 2022 x64/x86).
2. Installez le **DirectX End-User Runtime**.
3. Assurez-vous d'avoir désactivé le **Secure Boot** dans le BIOS si le driver nécessite le mode Test.
4. Lancez l'outil `SupportTool.bat` inclus dans le dossier Mega en Administrateur pour nettoyer le cache de drivers.
