# 🌌 Public Emulator (TPM 2.0 & HVCI Bypass)

The Public Emulator allows seamless gameplay across Windows 10 & 11 environments requiring TPM 2.0, Secure Boot, and HVCI compatibility without modifying BIOS keys or rebooting between matches.

---

### 🛡️ Key Features
* **Zero-Reboot Architecture :** No system restarts required to activate emulation.
* **Full OS Compatibility :** Supports all Windows 10 & 11 builds (including 23H2 and 24H2).
* **Universal Hardware Support :** Compatible with Intel and AMD processors across all motherboard brands (ASUS, MSI, Gigabyte, ASRock, etc.).

---

### 🚀 Quick Start
1. Ensure Riot Vanguard and Valorant are closed.
2. Run the Emulator loader as **Administrator**.
3. Enter your license key.
4. Click **Initialize Emulator**.
5. Once `[ EMULATOR ACTIVE ]` appears, launch **Riot Vanguard** then start **Valorant**.
