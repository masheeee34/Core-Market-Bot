# ⚡ Triggerbot Standalone — User Guide

The **Triggerbot** automatically triggers shots at sub-millisecond speeds the moment an opponent crosses your crosshair.

---

### ⚙️ 1. Key Settings

| Parameter | Description | Recommended Value |
| :--- | :--- | :--- |
| **Delay Before Fire** | Millisecond delay before the first bullet | `40ms - 80ms` (Legit) / `0ms` (Instant) |
| **Delay Between Shots** | Delay between consecutive burst shots | `120ms - 180ms` |
| **Keybind** | Trigger activation key | Mouse Button 4/5 or `Shift` |
| **Trigger Mode** | Hold or Toggle mode | `Hold` |

---

### 💡 Sniper & Operator Strategy (Operator / Marshal)
* For snipers, set **Delay Before Fire** to `0ms` or `15ms`.
* Hold narrow sightlines with confidence: the shot fires automatically the exact frame the opponent peeks.
