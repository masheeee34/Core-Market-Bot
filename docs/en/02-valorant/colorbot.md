# 🎯 Colorbot (Full & Lite) — User Guide

The **Valorant Colorbot** processes high-speed on-screen pixel buffers in real-time to lock onto enemy outlines without injecting code into game memory.

---

### ⚙️ 1. In-Game Settings (Valorant)
1. Launch **Valorant**.
2. Go to **Settings** > **General** > **Accessibility**.
3. Set **Enemy Highlight Color** to:
   * **Purple (Deuteranopia)** *(Recommended)*
   * **OR Yellow (Protanopia / Deuteranopia)**
4. Set Display Mode to **Fullscreen Borderless** or **Fullscreen**.

---

### 🎛️ 2. Recommended Profiles

#### « Legit » Configuration (Human-like tracking)
* **FOV (Aim Radius) :** `25 - 40`
* **Smooth (Smoothing Factor) :** `15 - 25`
* **Target Bone :** Head / Neck

#### « Semi-Rage » Configuration
* **FOV :** `60 - 90`
* **Smooth :** `4 - 8`
* **Target Bone :** Head

---

### 🌐 Live Web Dashboard (Colorbot Full)
With **Colorbot Full**, you can tune all sensitivity, target zones, and FOV parameters live from your smartphone or second monitor via the browser.
