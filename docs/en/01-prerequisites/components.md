# 2. Required Runtimes & Dependencies

To avoid missing DLL errors such as `VCRUNTIME140.dll missing` or `D3DCompiler not found`, you must install the official Microsoft C++ and DirectX runtimes.

---

### 1. Visual C++ Redistributable All-In-One (AIO)
This package installs all official versions of Microsoft Visual C++ from 2005 to 2026 in a single automated installer.

* Download the **Visual C++ AIO** package.
* Extract the ZIP archive.
* Right-click on `install_all.bat` > **Run as Administrator**.
* Allow the automated installation to complete.

---

### 2. DirectX End-User Runtimes
* Download the official Microsoft DirectX Web Installer.
* Run the installer, uncheck the Bing bar if prompted, and complete the installation.

---

### 3. System Reboot
Once both packages are installed, **restart your computer**.
