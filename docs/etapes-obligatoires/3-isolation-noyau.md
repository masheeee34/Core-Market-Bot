# 3. Désactivation de l'Isolation du Noyau (HVCI)

{% hint style="warning" %}
Certains loaders externes nécessitent que l'intégrité de la mémoire (HVCI) soit désactivée pour communiquer avec le matériel sans conflit.
{% endhint %}

---

### ⚙️ Comment désactiver l'Isolation du Noyau :

1. Ouvrez **Sécurité Windows**.
2. Cliquez sur **Sécurité des appareils** dans le menu de gauche.
3. Sous **Isolation du noyau**, cliquez sur **Détails de l'isolation du noyau**.
4. Désactivez l'option **Intégrité de la mémoire**.
5. **Redémarrez votre PC** pour appliquer les modifications.
