# 4. Configuration Overlay & Graphismes

Pour que les menus visuels (ESP, Chams, Menus de configuration) s'affichent correctement par-dessus le jeu :

---

### 🖥️ Mode d'Affichage en Jeu
* Dans les paramètres graphiques de votre jeu (Black Ops 6 / Warzone / Valorant) :
  * Réglez le mode d'affichage sur **Plein écran fenêtré (Borderless Windowed)** ou **Fenêtré**.
  * Évitez le Plein écran exclusif si votre overlay ne s'affiche pas au premier plan.

---

### 🎮 Désactivation des Overlays Tiers en Conflit
Si vous subissez des clignotements ou des crashs :
1. **Discord :** Paramètres utilisateur > Overlay de jeu > Désactiver l'overlay en jeu.
2. **NVIDIA GeForce Experience / Shadowplay :** Désactivez l'overlay en jeu dans les paramètres généraux.
3. **Steam :** Paramètres > Dans un jeu > Désactiver l'overlay Steam.
4. **RivaTuner Statistics Server (RTSS) / MSI Afterburner :** Fermez ces applications avant d'injecter le loader.
