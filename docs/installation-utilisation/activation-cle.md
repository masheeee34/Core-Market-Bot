# 🔑 Activation de la Clé d'Essai (Trial)

{% hint style="success" %}
Chaque membre du serveur Discord Core Market a droit à **1 clé d'essai gratuit de 1 heure**.
{% endhint %}

---

### 🎁 Récupérer votre clé d'essai

1. Rendez-vous sur le serveur Discord Core Market.
2. Allez dans le salon `#🔑・ꜰʀᴇᴇ-ᴛʀɪᴀʟ` (ou `#🔑・essai-gratuit`).
3. Cliquez sur le bouton vert **🎁 Claim Free Trial (1H)**.
4. Le bot vous délivre instantanément votre clé unique au format :
   `BO7-EXTERNAL-COREMARKET-TRIAL-XXXXXX-XXXXXX`

---

### 🚀 Activer la clé dans le Loader

1. Lancez le Loader téléchargé sur Mega en tant qu'administrateur.
2. Lorsque la fenêtre de commande s'ouvre, collez votre clé avec `Ctrl + V` ou clic droit.
3. Appuyez sur **Entrée**.
4. Le loader authentifie votre session (1 heure) et vous invite à lancer le jeu.
